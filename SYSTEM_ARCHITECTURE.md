# PAM Architecture Navigation

`SYSTEM_ARCHITECTURE.md` is a navigation aid, not a competing canonical
architecture specification.

Use the following sources according to purpose:

- `PAM_PROJECT_CONSTITUTION.md` — foundational architecture, product direction
  and investment philosophy;
- `governance/PAM_GOVERNANCE.md` — administrative authority and role model;
- `governance/PAM_CURRENT_STATE.md` — current administrative and operational state;
- `PAM_ROADMAP.md` — current technical and program sequence;
- `BASELINE_V1_FREEZE.md` — frozen V1 authority;
- active feature and technical contracts — detailed implementation boundaries;
- code and tests — executable technical truth.

The former pre-V2 overview is preserved at
`docs/history/SYSTEM_ARCHITECTURE_PRE_V2.md`.
