# V2 Contract Index

This directory organizes PAM's V2 technical contracts for navigation:

- `foundation/` — foundational V2 runtime, validation-identity and PIT contracts.
- `expected_return/` — the PR4/PR5 Expected Return and evidence-contract chain.
- `capabilities/` — capability and partial-analysis contracts.
- `validation/` — validation and CI-routing contracts.

Directory placement does not create or change authority. Code, tests, canonical
governance and the contracts' existing semantics remain authoritative according
to PAM's established hierarchy.
